v0.3.0 2026-06-18
🆕 需求模块增强
  • 新增FileReaderService 文件读取服务，支持 Word(.docx)、PDF、Excel(.xlsx)、XML、JSON、TXT 等 30+ 种格式
  • 新增RequirementPanel 组件：需求文档 + 参考材料分区管理，支持本地路径输入
  • 新增AI 综合分析：读取所有需求文档和参考资料，生成 Markdown 需求理解报告 + 结构化问题清单
  • 新增材料数据持久化到 storage/data.json
🔧 OLE 嵌入文件解析与预览
  • 新增使用 cfb 库解析 OLE Compound Document，提取 Package 流和 Ole10Native 流中的真实文件
  • 新增嵌入文件在线预览模态框：Excel 转 HTML 表格、PDF iframe 查看器、文本直接渲染、图片直接显示
  • 新增文件格式自动检测（魔术字节）：xlsx/xls/pdf/png/jpg/gif + 文本内容检测
  • 修复OLE 流名称含 \u0001 前缀导致匹配失败
  • 修复Ole10Native 数据段定位：采用"取最后一个精确匹配"策略
🌐 编码与乱码修复
  • 修复Word 文档图片使用 mammoth convertImage 转 base64 data URI，图片正常显示
  • 修复嵌入文件 GBK 编码检测：扫描整个文件查找非 ASCII 字节（不再只查前 1024 字节）
  • 修复iconv-lite ESM 动态导入 .default 问题：decode 函数需通过 .default 访问，之前静默回退 UTF-8 导致中文乱码
  • 修复Ole10Native 文件名 GBK 解码：使用 iconv-lite 从 GBK 转为 UTF-8
⚡ 文档格式渲染
  • 优化Word(.docx) → mammoth convertToHtml 富文本渲染（标题/列表/表格/图片）
  • 优化PDF → 浏览器内置 PDF 查看器 iframe
  • 优化Excel(.xlsx) → xlsx sheet_to_html 表格渲染（表头高亮/斑马纹）
  • 优化ZIP → adm-zip 解压展示文件列表和文本内容
  • 优化展开文件自动加载完整内容，内容截断上限提升至 500K 字符
新增文件: apps/api/src/requirement/file-reader-service.ts, apps/api/src/requirement/index.ts, apps/web/src/components/RequirementPanel.tsx
修改文件: apps/api/src/index.ts, apps/api/src/store.ts, apps/api/src/clarification/clarification-service.ts, apps/web/src/main.tsx, apps/web/src/styles.css, packages/shared/src/index.ts
